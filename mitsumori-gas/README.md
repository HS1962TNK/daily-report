# 見積・請求ポータル（母艦スプレッドシートの Apps Script）

このフォルダには「見積書テンプレート（母艦）」スプレッドシートに入っている
Apps Script のコードを置きます。

## 置き方

1. 母艦スプレッドシートを開き、「拡張機能」→「Apps Script」を開く
2. 左側のファイル一覧（`コード.gs` など）を1つずつ開き、中身を全部コピーする
3. GitHub でこのフォルダを開き、「Add file」→「Create new file」
4. ファイル名に Apps Script と同じ名前を入れる（例：`コード.gs`、`portal.html`）
5. コピーした中身を貼り付けて「Commit changes」
6. ファイルの数だけ 3〜5 を繰り返す

※ `.gs` と `.html` のファイルはすべて置いてください。

## 所在地（本社／大阪営業所）の切り替え（2026-10-07〜）

見積書の表紙の担当部署（J10）が「大阪営業所」のときは大阪営業所の所在地、それ以外の部署はすべて本社の所在地が表紙に入ります。
請求書は担当部署に関係なく本社扱いなので、切り替えません（請求書ひな形の所在地のまま）。
住所・電話番号などは母艦の「所在地設定」シートで管理します（コードを直さずに変えられます）。

| セル | 本社 | 大阪営業所 |
|---|---|---|
| J5（例） | 〒000-0000 東京都… | 〒000-0000 大阪府大阪市… |
| J7（例） | TEL 00-0000-0000 | TEL 06-0000-0000 |

### 初回の設定

1. `コード.gs` を母艦の Apps Script に反映する（clasp push → version → redeploy）
2. 母艦を開き直し、メニュー「見積書メーカー」→「所在地設定シートを作る（初回のみ）」
   - 見積ひな形の表紙から、会社名・住所・TEL・FAXらしいセルを拾って「本社」の列に入れます。合っているか確認してください
3. 「大阪営業所」の列には大阪営業所の内容（〒663-8002 兵庫県西宮市一里山町3-1-501／TEL・FAX 0798-31-7478）が自動で入るので、確認する
4. 見積ひな形の Apps Script を `見積ファイル側_コード_修正版.gs` の内容に置き換える
   （担当部署を選び直したときに自動で切り替える処理が入っています）

### 動き

- 見積を新しく作る・複製するたびに、母艦の所在地設定がそのファイルの「所在地設定」シート（非表示）に写され、表紙に反映されます
- 見積ファイルで担当部署を選び直すと、表紙の所在地がその場で切り替わります
- 作成済みの古い見積ファイルは、メニュー「見積機能」→「所在地を担当部署に合わせる」で切り替えられます
  （古いファイルにこのメニューが無い場合は、そのファイルの Apps Script も置き換えてください）
